+ #Project: To-Do List Application

#Overview
This project is part of the Decode Labs Python Programming Internship. It is a command-line application designed to help users manage, organize, and track their daily tasks efficiently.

#Objective
To build a simple, functional task management tool that demonstrates core Python concepts, such as data structures, file handling, and user interaction through a command-line interface.

#Features
Add Tasks: Allows users to create new task entries.
View Tasks: Displays the current list of tasks with their respective status.
Mark as Completed: Updates the status of selected tasks from pending to complete.
Delete Tasks: Enables users to remove completed or unneeded tasks.
Persistent Data: Saves tasks to a file so information persists between application runs.

##Skills Demonstrated
Utilizing Python list and dictionary structures for dynamic data storage.
Using file input/output (open, read, write) to implement data persistence.
Building interactive menu loops and using conditional logic (if-elif-else).
Handling input processing and fundamental error management.
Functions and modular design principles.

##How to Run
Ensure Python is installed on your system.
Navigate to the project directory in your terminal.
Run the script using the command: python main.py
Use the menu options displayed on the terminal to interact with your to-do list.
